Installation

  1. Install ESPHome on your computer or Home Assistant.
  2. Add Roode as an external component in your YAML: 
    external_components:
  - source: github://Lyr3x/Roode
  3. Copy one of the example configs from the GitHub repository and adjust as needed.
  4. Flash your device with esphome run yourfile.yaml.
